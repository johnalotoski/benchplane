# Nix packages

The flake's default package builds the Benchplane Rust CLI using the checked-in `Cargo.lock` and combines it with the fixed CPU-probe helper, CPU-only llama.cpp helper/backend, and immutable SmolLM2-135M-Instruct Q2_K fixture on both supported architectures. The separate `packages.x86_64-linux.benchplane-nvidia-cuda` output adds the fixed CUDA helper and pinned CUDA-enabled llama.cpp b10133 closure and is the only package that accepts the public `nvidiaCuda` target. The model source is QuantFactory's Apache-2.0 GGUF at commit `c33bd7b3a0c1c5048af630f0198eb2a29977b422`; its 88,201,792-byte content is pinned by SHA-256 `55aa88ddac43adce6af0e9be8d6cdff2337a3835cd9b50bbcd7a894eb66dfc75`. Neither package exposes llama.cpp's general-purpose CLIs. The CUDA output's model, MIT-licensed engine and CUDA closure increase package size but avoid every runtime download; actual NVIDIA execution still requires the host driver/device interface outside the Nix store, and the helper rejects driver versions older than 610.43.03 before backend initialization.

Keep future vLLM packaging separate from this Benchplane package so native-Nix and container runtime variants can share the surrounding node configuration.
