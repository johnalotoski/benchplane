# Tasks

Task documents are implementation briefs that may be executed by humans, Codex, Claude Code, Gemini CLI, or other agents. They must remain tool-neutral unless a requirement genuinely depends on a particular tool.

Each task should include:

- objective;
- context;
- required outcomes;
- constraints;
- non-goals;
- verification commands;
- expected completion report.

Completed tasks may be retained under `tasks/completed/` when their acceptance criteria provide useful historical context. This repository does not require a particular issue tracker or agent workflow.
